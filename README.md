# metrolimaGO

Android app that guides tourists in Lima: where to go and at which stop to get off on public transport, for visitors who don't know the city.

## Features
- Route guidance for tourists using Lima's public transport
- Maps and images of Metro Line 2 and bus corridors
- Spanish and English support
- Chatbot to answer visitors' questions

## Tech stack
- Android (built with Gradle in Android Studio)

## Status
Prototype in development. The chatbot originally used the Gemini API free tier, which stopped working. We plan to rebuild it with the Claude API as a multilingual travel assistant that answers tourists' questions in their own language and suggests nearby places.
